    Cómo usar

    Pasa de página con las flechas de los lados o deslizando el dedo. Al terminar un capítulo, sigue el siguiente.

    Toca las palabras subrayadas para ver el griego original.

    Toca el número de página, arriba a la derecha, para saltar a cualquier sección o cambiar de capítulo.

    Vuelve a este índice con el botón de arriba a la izquierda. Tu avance queda guardado en este dispositivo.
